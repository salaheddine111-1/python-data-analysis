# 📊 Customer Behavior & Sales Data Analysis

An exploratory data analysis (EDA) project using Python to uncover actionable insights, clean raw data, and visualize key trends in customer purchasing behavior.

---

## 🚀 Project Overview
This project focuses on analyzing a retail sales dataset to answer critical business questions:
- What are the top-selling product categories?
- How do sales trend over time?
- What are the key demographics or patterns of high-value customers?

---

## 🛠️ Tech Stack & Libraries
- **Python** (Programming Language)
- **Pandas & NumPy** (Data Manipulation & Cleaning)
- **Matplotlib & Seaborn** (Data Visualization)
- **Jupyter Notebook** (Development Environment)
